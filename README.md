MEGHALAYA JOB CONNECT

Tagline:
“Connecting Meghalaya with the right opportunities.”

IMPORTANT:
This is not just a demo landing page. Build the complete full-stack website architecture with a modern responsive frontend, backend, database, authentication, payments, job posting, job searching, applications, notifications, admin panel, verification, and security.

The website must work beautifully on mobile phones, tablets, and desktop computers.

TARGET USERS:
1. Job Seekers — people looking for work
2. Job Providers — people, businesses, organizations, schools, families, companies, etc. looking to hire someone

The platform is intended for Meghalaya, India.

49. IMPORTANT DEVELOPMENT RULE
==================================================

Build this in phases rather than pretending everything is already connected.

PHASE 1:
Frontend + database + authentication

PHASE 2:
Job seeker/provider profiles

PHASE 3:
Job posting + job search

PHASE 4:
Applications + dashboards

PHASE 5:
Messaging + notifications

PHASE 6:
Payments + subscriptions + invoices

PHASE 7:
Verification + reports + safety

PHASE 8:
Admin dashboard

PHASE 9:
Testing + security

PHASE 10:
Production deployment

At every phase:

- Show what has been completed
- Show what remains
- Test the feature
- Do not create fake payment success
- Do not claim production readiness until it has actually been tested
- Use real backend/database connections where required
- Keep the code organized and documented
